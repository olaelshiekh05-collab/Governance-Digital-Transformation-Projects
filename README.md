# Governance-Digital-Transformation-Projects
Individual projects developed during the Governance and Digital Transformation Ambassadors Program
Prepared by: Ola Yasser Elsheikh

Welcome to my project portfolio, featuring three individual projects developed during the Governance and Digital Transformation Ambassadors Program, organized by Engineers for Sustainable Egypt in collaboration with Nile University's School of Continuing Education.

These projects explore governance, sustainable development, resource efficiency, and the practical application of analytical tools to support institutional improvement and sustainability.

Projects

1. Governance Maturity Assessment of Telecom Egypt (WE)

An independent analytical assessment exploring governance effectiveness, stakeholder engagement, risk management, and digital transformation readiness.

Key Topics:

Governance principles and maturity scoring

SWOT and stakeholder analysis

Enterprise risk assessment

MATLAB-based data visualization

Strategic recommendations for institutional improvement

Files: Project report (PDF), presentation, and MATLAB code where available.

2. Hayah Karima: Sustainable Development Assessment

An analytical study of Egypt's Hayah Karima initiative and its contribution to rural development and quality of life.

Key Topics:

Social and economic development

Infrastructure and public services

Alignment with the Sustainable Development Goals (SDGs)

Governance, accountability, and sustainability

Data visualization and impact assessment

Files: Project report (PDF) and presentation.

3. 30-Day Sustainability Action Plan

A practical sustainability plan designed to encourage environmentally responsible practices and improve resource efficiency.

Key Topics:

Paper consumption reduction

Electricity and plastic usage reduction

Sustainable Development Goals (SDGs)

Workplace recycling practices

MATLAB simulation and visualization

Files: Project report (PDF), presentation, and MATLAB code where available.

Skills Demonstrated

Governance and Institutional Assessment

Sustainable Development and SDG Alignment

Risk and Stakeholder Analysis

Data Analysis and Visualization

MATLAB

Strategic Thinking and Report Writing

Purpose

This portfolio documents my learning journey and demonstrates how governance, digital transformation, analytical thinking, and sustainability can contribute to better institutional practices.

Note: These projects were developed for educational purposes. The Telecom Egypt governance assessment is an independent analytical exercise and does not represent an official assessment by the company.
